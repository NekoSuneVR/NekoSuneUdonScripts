# NekoSune World Data

VRChat remote-data helpers for the NekoSune World Hub.

- test JSON/text URLs in the Unity Editor
- generate `VRCStringDownloader` + `VRCJson` UdonSharp starters
- generate `VRCImageDownloader` + `RawImage` starters
- starter JSON feeds for news, event boards, catalogs and UI data
- beginner-facing warnings for trusted URL rules, queue/rate limits and image memory disposal

Generated runtime scripts are placed in `Assets/NekoSune/Data/Generated/` so the creator can inspect and edit them.
