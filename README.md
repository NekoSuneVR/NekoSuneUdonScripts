# NekoSune World Economy

Beginner-focused VRChat Creator Economy helpers.

- product ownership unlock starter
- `OnPurchasesLoaded` lifecycle-safe ownership checks
- quantity-aware `OnPurchaseConfirmedMultiple`
- world store / listing buttons
- supporter wall using `Store.ListProductOwners`
- starter world-space Store UI

This package does **not** process payments. VRChat's own Creator Economy handles Credits, listings and purchases. The addon only helps wire world-side Udon behaviour.

`ListProductOwners` requires the product's **Owners Names in Udon** option to be enabled on VRChat.com.
