# NekoSune Worlds Bundle

`com.nekosune.worlds` is now a compatibility/bundle package.

It contains no duplicate editor implementation. Installing it pulls in:

- **NekoSune World Tools** — world framework + Template Guide
- **NekoSune Optimizer** — World Optimizer plus shared optimization tooling
- **NekoSune Doctors** — World Doctor + Udon Network Doctor
- **NekoSune Converters** — VRChat World → ChilloutVR plus Avatar/Prop/Resonite converters

Individual modules are available from the same VCC repository:

```text
https://nekosunevr.github.io/NekoSuneUdonScripts/index.json
```
