# NekoSune Avatars Bundle

`com.nekosune.avatars` is now a compatibility/bundle package.

It intentionally contains no duplicate editor implementation. Installing it pulls in:

- **NekoSune Avatar Tools** — Lip Sync Studio + Rank Advisor
- **NekoSune Optimizer** — Compressor, Mesh, Quest, VRAM and optimization tooling
- **NekoSune Doctors** — Avatar/PhysBone/Face/Animator diagnostics
- **NekoSune Converters** — ChilloutVR Avatar/Prop/World + Resonite

New projects can install those packages individually from the same VCC repository.

```text
https://nekosunevr.github.io/NekoSuneUdonScripts/index.json
```
