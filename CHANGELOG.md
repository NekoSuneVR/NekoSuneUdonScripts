# Changelog

## 1.0.0

- Added beginner-first World UI Builder for VRChat, ChilloutVR and generic Unity world-space UI.
- Added editable/exportable JSON blueprints instead of fixed hard-coded layouts.
- Added templates for settings, mirrors, teleports, media, image galleries, supporter/Patreon walls, shop/catalog panels, social/link panels, credits, player interactions, admin/debug panels, rules and event schedules.
- Added editable Neko Dark, Light, Neon, Glass, Pastel, Terminal and Custom themes with configurable colors, spacing, padding, text size and control height.
- Added local/remote JSON snapshot importer and example feeds for supporters, shops, events, galleries, staff, leaderboards and links.
- Added real RawImage slots for local textures and runtime image placeholders.
- Added VRChat and ChilloutVR platform setup through optional SDK reflection.
- Added safe Unity action wiring for object/page/audio actions and explicit platform-runtime warnings for player/Animator/network actions.
- Added UI Doctor and beginner learning/explanation panel.
- Added generated VRChat runtime starter scripts for JSON, remote image loading and common player/action methods.
- Fixed platform helper naming and proper RectTransform-based UI hierarchy creation before release.
